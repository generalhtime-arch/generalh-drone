# OGP image

共通OGP画像は `default.jpg` です。実在の会場写真を用いず、校名と講習内容を示す共有用カードにしています。編集用の元データは `default.svg` です。

- 推奨サイズ: 1200 × 630px
- 利用する絶対URL: `https://drone.general-h.com/assets/images/og/default.jpg`
- 画像を差し替えた後は `./tools/enable-og-image.ps1` を実行し、すべてのページの設定を更新します。

画像を配置した後は、ローカルWindows PCで `./tools/enable-og-image.ps1` を実行します。詳細は[画像配置仕様](../README.md)を参照してください。
